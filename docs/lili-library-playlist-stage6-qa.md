# 音乐库与播放列表阶段 6 验收记录

> 日期：2026-09-22  
> 窗口：macOS Electron，1200 × 800

## 验收范围

1. 侧栏“发现音乐 / 我的音乐 / 更多”信息层级。
2. “我的收藏”聚合页及未登录状态。
3. 收藏夹、合集、系列共享 `PlaylistDetail` 布局。
4. 单曲与批量播放、队列、收藏、下载及来源跳转。
5. 收藏夹、合集、系列批量下载的数据来源分流。

## 结果

- 未登录收藏页空态清晰，说明数据来自当前 B 站账号。
- 空导航分组已修正为整体隐藏。
- 1200 × 800 窗口下未发现横向溢出，应用壳层与播放栏布局稳定。
- 三类详情页已共享头部、操作区、Track 列表/网格和动作执行器。
- 系列批量下载不再误用合集接口，改为通过系列元数据与分页接口加载完整曲目。
- 破坏性收藏夹操作仍保留原确认流程。
