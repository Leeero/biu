## 验收结果

阶段 4 的代码迁移与 macOS 开发环境回归通过。Windows、Linux 的窗口级检查保留到发布回归阶段执行。

## 架构检查

- 播放状态继续由 `usePlayList` 和 `usePlayProgress` 维护，没有新增第二份播放状态。
- 主窗口播放操作统一通过 Player Action API 调用现有 store。
- Mini 播放器通过语义一致的动作适配器发送现有 BroadcastChannel 命令。
- 本地音乐、视频音轨和 Bilibili 音频使用稳定身份生成可见队列。
- 歌词解析、排序和当前行计算从界面组件中分离。
