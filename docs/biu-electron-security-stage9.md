# Biu 阶段 9：Electron 安全基线

更新日期：2026-09-23

## 本轮完成

- 保持 `contextIsolation: true`、`nodeIntegration: false` 和 `webSecurity: true`，主窗口与迷你播放器新增 `sandbox: true`。
- preload 仅暴露业务级方法，未暴露原始 `ipcRenderer` 或任意通道调用能力。
- 新增统一运行时校验，覆盖 HTTPS 外链、绝对路径、代理配置、Cookie、快捷键、下载任务及 Store 名称。
- 本地文件删除限制为当前支持的音频扩展名，避免该 IPC 被用于删除任意类型文件。
- 所有 Electron 新窗口请求保持拒绝；主窗口和迷你播放器仅允许导航到打包后的应用入口文档。
- 生产环境不再响应打开开发者工具的 IPC。
- HTML 增加 CSP：脚本仅允许本地来源，禁用对象嵌入，限制连接、图片、媒体和字体来源。
- 所有业务 IPC 统一校验调用来源，仅接受当前 Biu 应用文档；歌词服务请求增加 ID、分页和搜索文本边界。

## 验证结果

- ESLint：本轮涉及文件通过。
- Vitest：23 个测试文件、101 个测试通过，其中新增 6 个 Electron 安全边界测试。
- Web 与 Electron 主进程/preload 编译成功；构建进入 macOS 打包阶段后按既定策略停止。
- 开发版 Electron 实机启动成功：首页正常渲染、在线推荐数据可见，说明 sandbox、CSP 与 preload 基础链路可工作。
- `tsc --noEmit` 仍受既有第三方声明与项目存量类型错误影响；本轮新增文件未在 ESLint、Vitest 或实际编译中产生错误。

## 性能优化第一轮

- 通用远程图片默认使用原生懒加载和异步解码，首屏明确需要的图片仍可覆盖为 eager。
- 频谱绘制由屏幕刷新率降至最高 30 FPS；减少动态效果偏好下为 15 FPS；暂停或文档进入后台后停止动画。
- 频谱复用频域数据缓冲，避免每帧创建 `Uint8Array`，并将不变的画笔颜色移出柱形循环。
- 全屏模糊背景请求 672×378 的 B 站图片变体，不再用原始大图做全窗口模糊；取色结果最多缓存 100 项。
- 模糊半径不再参与每次背景切换动画，也不再长期声明 `filter` 和 `transform` 的 `will-change`。
- 首页以外的主要路由改为按访问加载，并增加统一的无障碍加载状态。

构建前后主要首屏块对比：

| 产物          |                    优化前 |                    优化后 |      变化 |
| ------------- | ------------------------: | ------------------------: | --------: |
| 业务入口 JS   |  402.1 kB / 111.6 kB gzip |   264.6 kB / 80.3 kB gzip | gzip -28% |
| 主共享块 JS   | 1528.4 kB / 435.9 kB gzip | 1155.4 kB / 329.1 kB gzip | gzip -25% |
| 两者合计 gzip |                  547.5 kB |                  409.4 kB | gzip -25% |

异步页面会产生独立小块，因此全部产物总量略有增加；启动时不再下载和解析这些未访问页面。开发版已实机验证本地音乐与下载管理页面可以正常按需加载。

## 清理结果

- Knip 未发现未引用文件或未使用依赖。
- 将 IPC 可信发送方判断收回为安全模块内部实现，不再暴露无调用方的导出。
- 删除没有处理器和调用方的旧 Store、文件、HTTP、下载及更新 IPC 通道常量。
- 保留 `dynamic-feed` 实现，因为新的“关注 > 最新动态”仍在复用；旧 `/dynamic-feed` 路径继续仅作为兼容重定向。
- 保留旧设置迁移和导入兼容逻辑，避免破坏已有用户数据。
- README 的功能说明已按重构后的音乐播放器结构更新。
