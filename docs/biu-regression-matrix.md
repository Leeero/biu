# Biu 2.0 功能回归矩阵

> 目的：在界面重构期间保证现有能力不丢失，不把“视觉完成”误判为“产品完成”。本矩阵只覆盖当前项目和现有后端已经具备的能力，不引入新接口。

## 1. 使用规则

- P0：音乐播放器主链路，任一失败都阻止合并。
- P1：高频管理能力，发布前必须通过。
- P2：低频或外围能力，可在对应模块迁移时验证。
- 自动：纳入 Vitest；半自动：自动检查状态，人工检查媒体或系统集成；人工：需要真实账号、网络或桌面系统。
- 每完成一个重构阶段，都执行该阶段涉及项以及全部 P0 项。

## 9. 阶段准入标准

### 进入视觉重构前

- P0 播放 Store 行为具备自动化覆盖。
- 设置和播放进度持久化具备自动化覆盖。
- 当前生产构建通过，并记录尚未自动化的桌面/账号场景。

### 每个页面迁移完成

- 该页面涉及的 P0/P1 场景通过。
- 加载、空、失败、无权限四类状态均经过检查。
- 不增加未在现有 service、Electron IPC 或本地能力中出现的入口。

### 发布候选版本

- 全部 P0、P1 通过；P2 遗留有明确记录。
- macOS 完成一次真实账号、在线播放、本地播放、下载与重启恢复的冒烟测试。
- `pnpm test --run` 与 `pnpm build` 通过。
