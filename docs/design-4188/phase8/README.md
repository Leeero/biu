# 阶段 8：响应式、无障碍、动效与系统窗口收口

## 已完成实现

- 将真实 Mini 窗口从 360 × 112 调整为 360 × 140，为 108 px 封面、进度和 44 px 控件提供稳定空间。
- 为 Mini 的封面、内容、进度、控制区和五个按钮建立可追踪类名，并统一使用 4188 令牌、焦点环和动效规则。
- 将系统集成页的操作区、曲目表和平台卡片补齐响应式结构；720 px 下操作胶囊自动换行，表格转为可读的两列卡片行。
- 将主壳返回/前进、播放队列及 900 px 以下启用按钮统一到至少 44 × 44 px 的触控目标。
- 修复 390 px 设置分类逐字换行，改为单行横向滚动；下载管理继续保持无遮挡、无横向溢出。
- 增加全局 `prefers-reduced-motion: reduce` 降级，并将发现页和队列中的硬编码时长迁移到运动令牌。
- 保留主窗口/Mini 状态广播、媒体键、托盘、窗口关闭策略和全部播放业务逻辑。

## 设计与功能依据

- 视觉基准：`prototypes/biu-discover-option2/src/Pages.jsx` 与 `styles.css` 中设置页 Mini 预览、深色表面、蓝色强调色、圆角和控制层级。
- 功能基准：`electron/mini-player.ts`、`src/common/utils/mini-player.ts`、`src/pages/mini-player/index.tsx` 的现有窗口与状态同步行为。
- 设计稿仅展示三键简版 Mini；当前项目还包含播放模式、进度、上一首/下一首和返回完整播放器。按“现有功能不弱化”约束，目标实现沿用同一设计语言承载完整功能。

## 可验证结果

- 真实 Electron：使用 `⌘M` 完成完整播放器 → Mini → 完整播放器双向切换；曲目、作者、进度和播放状态保持一致。
- Mini：360 × 140 实窗中五个控制按钮均可访问；浏览器测量均为 44 × 44 px；键盘 Tab 顺序跳过禁用控件并可到达播放模式与返回入口。
- 720 × 900：根节点无横向溢出，系统集成操作区与曲目行不裁切，所有可见启用按钮不小于 44 × 44 px。
- 390 × 844：下载管理和设置页无横向溢出，移动导航/播放器不遮挡内容。
- 回归：Vitest 44 个文件、460 项测试通过；Web-only 构建、设计字面量门禁和 4188 源文件哈希锁通过。
- 完整构建：Electron 主进程、preload 与 Web 产物成功生成；macOS 打包在系统 `actool/CoreSimulatorService` 环节失败，属于本机 Xcode 服务阻塞，不是源码编译错误。

## 回退边界

本阶段改动集中于 Mini 窗口尺寸、样式类、系统集成响应式布局、触控尺寸和 reduced-motion。若需回退，可分别恢复这些表现层文件；IPC、store、播放队列、快捷键和持久化 schema 无需回退。
