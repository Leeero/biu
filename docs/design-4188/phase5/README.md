# 阶段 5：音乐资产与内容管理

## 已完成范围

- 我的音乐：真实路径迁移为 4188 的页面标题、操作药丸、概览统计与资产卡片；保留创建/收藏/本地目录三类入口和原有动作。
- 收藏夹/合集/系列详情：统一为 4188 的详情页头、批量操作和曲目列表；所有权、权限、编辑、清理失效、批量下载、删除等原 handler 不变。
- 稍后播放：迁移筛选、统计、批量操作和行内动作；保留分页、搜索、类型筛选和删除能力。
- 本地音乐：迁移为设计稿的目录导航 + 曲目列表；保留扫描、目录筛选、播放、下一首、添加列表、定位文件和删除文件确认。
- 观看历史：迁移日期筛选、搜索、分页、清空与逐条删除；保留历史上报、下载和队列动作。
- 公共资产列表：新增 `AssetTrackList`，统一序号、封面、当前项、元信息、时长/格式及悬停操作带；动作图标复用全局图标词汇表。
- 兼容：原 C+ fixture 仍保留旧呈现；真实业务路径使用 4188 呈现，`preview=4188` 仅用于确定性视觉验收。

## 功能边界核对

- 未新增远程接口、收藏类型或目录能力。
- 未删除设计稿未展示的业务动作；这些动作进入统一页头操作或行内操作带。
- 数据获取、权限判断、分页、持久化、播放、下载和 Electron IPC 均沿用原实现。
- 空、加载、错误、未登录和无权限继续由阶段 3 的 `PageState`/权限分支呈现。
