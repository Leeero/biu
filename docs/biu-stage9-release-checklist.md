## 4. 全新安装回归

- [ ] 安装、首次启动、退出和再次启动正常。
- [ ] 主窗口尺寸、拖动区、最小化、最大化和关闭策略正常。
- [ ] 登录 Cookie 可写入、读取和退出清理。
- [ ] 发现、搜索、音乐库、稍后播放、历史、本地音乐和下载页面可进入。
- [ ] 在线音乐、本地音乐可以播放、暂停、切歌、拖动进度和调节音量。
- [ ] 单曲循环、列表循环、顺序与随机播放可切换。
- [ ] 播放队列可增删、重排、清空，并在重启后保持预期状态。
- [ ] 歌词、全屏播放器和 mini 播放器工作正常。
- [ ] 收藏、取消收藏、稍后播放和下载能力遵循内容 capability。
- [ ] 下载视频、提取音频、暂停、恢复、取消和打开目录正常。
- [ ] 主题、字体、主色、圆角、播放栏和菜单设置生效。
- [ ] 全局快捷键、托盘和系统媒体控制在支持的平台正常。
- [ ] 外部链接由系统浏览器打开，应用内不能导航到任意外部页面。

## 5. 从 1.16.0 覆盖升级

升级前在 1.16.0 中准备一套非空数据，然后安装新版本并逐项核对：

- [ ] 登录状态与 Cookie 保留。
- [ ] 应用设置和主题设置保留。
- [ ] 快捷键设置保留且可重新注册。
- [ ] 播放队列、当前播放项和可恢复进度未被破坏。
- [ ] 收藏夹与稍后播放数据可读取。
- [ ] 歌词缓存可读取，缓存失效时能安全重新获取。
- [ ] 下载记录和已下载文件路径可读取。
- [ ] 搜索历史可读取。
- [ ] 全屏播放器设置可读取。
- [ ] 旧字段缺失或异常时使用安全默认值，不导致白屏或主进程崩溃。
- [ ] 回退到上一正式版本时不因新字段而无法启动。

重点持久化 Store：`app-settings`、`user-login-info`、`shortcut-settings`、`lyrics-cache`、`media-downloads`。测试时应备份整个 Electron `userData` 目录，不直接修改用户真实数据。

## 6. 性能与稳定性抽检

- [ ] 冷启动和首次可交互时间相比阶段 0 基线无超过 10% 的非预期退化。
- [ ] 空闲 10 分钟后内存和 CPU 无持续增长。
- [ ] 连续播放 30 分钟无中断、音频重复或队列错位。
- [ ] 频谱在窗口不可见时停止绘制，恢复后正常继续。
- [ ] 500 首以上列表滚动无明显长任务和图片解码阻塞。
- [ ] 全屏播放器背景虚化切换不造成持续高 CPU/GPU 占用。

## 7. 发布后烟雾测试

- [ ] Release 页面包含全部预期产物，命名与架构正确。
- [ ] README 下载链接进入当前仓库最新 Release。
- [ ] 从上一正式版触发检查更新，命中新仓库发布源。
- [ ] 随机下载每个平台至少一个产物并校验可安装。
- [ ] 崩溃、更新失败和下载失败日志不包含 Cookie、路径外的敏感内容或完整请求凭据。

发现阻断问题时停止发布，将 Release 保持为草稿或预发布；修复后必须重新生成同一版本的全部平台产物，不能混用不同提交生成的文件。
