# Biu 下一版本发布说明（草案）

这一版本完成了以“音乐播放器”为核心的整体重构。在不增加后端依赖的前提下，重新组织了发现、搜索、音乐库、本地音乐、下载和创作者内容，并统一了主窗口、播放栏、全屏播放器与 mini 播放器的视觉和交互。

## 主要变化

- 全新的桌面音乐播放器界面，减少视频产品感，强化歌曲、歌单和播放队列。
- 新的一级导航与音乐库，将创建/收藏的歌单、本地音乐和下载内容组织得更清晰。
- 统一的歌曲行、卡片、菜单、空状态和加载状态，操作位置与反馈更加一致。
- 重构底部播放栏、播放队列、歌词、全屏播放器和 mini 播放器。
- 保留发现、搜索、收藏、稍后播放、历史记录、本地音乐、下载、关注与创作者内容等已有能力。
- 继续兼容原有 Bilibili 登录和数据来源，没有引入新的后端 API 依赖。

## 稳定性与性能

- Electron 窗口启用沙箱，并加强 IPC 参数校验、来源校验、CSP、外链和导航限制。
- 优化首屏代码分包、长列表、图片加载、背景虚化和频谱绘制。
- 清理废弃组件、IPC 通道和未使用依赖，补充核心播放、队列、设置、下载和页面模型测试。

## 升级说明

- 支持从 1.16.0 覆盖升级，目标是保留登录、设置、快捷键、播放数据、歌词缓存和下载记录。
- 正式发布前仍需完成 Windows、macOS 和 Linux 的安装包及真实旧版数据升级回归。
- 本项目为非官方客户端，与哔哩哔哩无官方关联；部分在线内容能力可能受账号权限和上游接口变化影响。

## 已知事项

- macOS 和 Windows 未签名安装包可能触发系统安全提示，最终说明以正式 Release 页面为准。
- Linux 不同发行格式的自动更新能力存在差异，不支持原地更新时会引导到下载页。
- 正式版本号、产物列表、签名状态和校验信息将在三平台发布验证完成后补充。
